# Numberblocks Sudoku

一个基于 Numberblocks 表情的数独游戏，面向儿童与家庭场景（React + TypeScript），包含两条体验路径：

- 幼儿冒险模式（约 4–8 岁）：4×4、四个 2×2 小宫、按行/列/宫学习、本地星星进度
- 经典数独模式：9×9 数独、撤销重做、备注与提示

## 快速开始

### 环境要求

- Node.js 18+
- npm 9+

### 安装与运行

```bash
npm install
npm run dev
```

启动后访问终端输出的本地地址（Vite 默认地址）。

### 构建与预览

```bash
npm run build
npm run preview
```

### 测试

```bash
npx vitest run
```

## 项目目标

本项目尝试把“低龄数字启蒙”和“经典数独练习”放在同一个产品中：

- 幼儿路径强调低认知负担与即时反馈
- 经典路径保留完整解题工具链
- 支持家庭场景下的亲子互动与渐进学习

## 功能说明

### 幼儿冒险模式

- 首页点击“开始冒险”进入
- 4×4 棋盘，四个小宫；第 1–3 关分别看行、列、小宫，第 4–6 关自己找只剩一个空位的一组
- 放重复时指出那一组，可以看一步、听一听、撤销、重做、拿走
- 完成要满足行、列、宫都是 1–4；进度存在 `localStorage` 键 `numberblocks.kid-progress.v1`

阶段路线和每轮验证记在 [docs/learning-roadmap.md](docs/learning-roadmap.md)。

### 经典数独模式

- 首页点击“经典数独”进入
- 9x9 棋盘，支持点击与拖拽输入
- 撤销 / 重做 / 清除 / 备注 / 自动备注 / 提示
- 错误上限判定与失败弹层

## 技术栈

- React 19

- Vite

## 项目结构

```text
src/
  components/          # 视图组件
  game/                # 通用状态、动作与工具
  hooks/               # 核心状态逻辑（useSudokuGame）
  kid-adventure/       # 幼儿闯关引擎与进度系统
  sudoku/              # 经典 9x9 数独引擎
tests/                 # Vitest 测试
```

## 开发建议

- 提交前至少运行：
  - `npx vitest run`
  - `npm run build`
- UI 改动优先补充对应测试，避免布局回退
- 幼儿模式与经典模式共享部分状态，修改时注意模式切换行为
