# 学习路线与维护记录

记录阶段路线、待办优先级、决策、实际验证和未解决项。按轮次追加，不另写日报。

## 2026-11-07

### 验收问题

幼儿路径把「和隐藏答案不一样」当成错误。旧第 3 关有 2 个合法完成，旧第 5 关至少 3 个；孩子按当时看得见的规则放入，也会被说「这里不是这个数字」。六关共用同一张答案。4×4 棋盘没有 2×2 宫的边界，底部提示却在讲 3×3。完成只对照答案，不检查行、列、宫是否都是 1–4。

### 受影响者

从「开始冒险」进入的 4–8 岁孩子，以及在旁边看反馈的家长。经典 9×9 本轮只确认没有被这处改动弄坏。

### 预期改善

- 放进已经出现过的积木时，句子指出是这一行、这一列还是这一小宫，并把这块积木留在盘上。
- 当前不冲突的放法会留下，即使它不是最终那一格。可以撤销、重做、拿走。
- 四行、四列、四个小宫都正好是 1、2、3、4 才算完成。
- 六关各自唯一解，答案互不相同，而且只靠「一组里只剩一个空位」就能做完。
- 「看一步」只讲当前盘面上的那一组，不替孩子填上。
- 四个小宫有粗框。手机上能打开玩法说明。幼儿界面不再显示计时和「错误 / 3」。

### 证明办法

规则用纯函数测试：唯一解、最后一组空位可解完、不读答案的冲突说明、拉丁方但宫不成立时不算完成。界面用浏览器在手机、平板、桌面宽度走通：放重复、撤销、看一步、通关、下一关、刷新后从下一关继续。不把设计评估写成儿童实测。

### 本轮只做这一件事

先修阻断规则：4×4 按看得见的行、列、小宫判断和解释。准备练习、6×6、9×9 方法难度、经典提示改写都未做。

### 决策

- 继续用 React、TypeScript、Vite、Vitest。规则可以抽成纯函数，现有 `numberblocks.kid-progress.v1` 只存星星和各关星数，换框架会重写界面又不能让学习记录更安全。
- 通关固定记 3 星，表示规则补齐，不再按失误扣星。沿用原来的解锁式 `2 + floor(星星 / 2)`。因此第一关拿到 3 星后，第 3 关也会打开；第 2 关仍显示「可以玩」，可以先做列。
- 题目写死在 `src/kid-adventure/engine.ts`。教学顺序要稳定，不能每次随机生成。

### 对照过的产品

未付费、未注册。没有操作过的不写成玩过。

1. [inSudoku](https://insudoku.com/)：实际打开了免注册的 Easy 棋盘，并点了一次 Coach。它先把中央宫标出来，写 “Only one cell is empty.”，数字要再按 “Show the digit” 才出现。难度页按推理方法而不是空格数分级。本轮「看一步」采用同一顺序：先指出那一组，不替孩子填。没有下完一局。
2. [Sudoku.com 入门策略](https://sudoku.com/how-to-play/sudoku-strategy-for-beginners/)：只读了文章，没有下那一局。文章教先找几乎满的宫和行。适合解释第 1–3 关为什么从「只剩一个空位」开始。页面面向成人 9×9，不能直接当幼儿界面。
3. [Good Sudoku 介绍](https://www.playgoodsudoku.com/presskit/)：只读了开发者说明，应用要安装且面向 iOS，没有玩。它把难度定义成所需技巧，并按当前笔记找下一步。适合以后的 9×9，句子对 4 岁太长。本轮没有照搬它的技巧目录。
4. [Numberblocks: Make and Play](https://www.bbc.co.uk/cbeebies/games/numberblocks-make-and-play)：只读了 CBeebies 介绍，页面里的游戏和视频没有跑起来。它把 4–5 岁的活动做成涂色、拼角色、短小游戏，角色就是操作对象。本轮继续用现有积木图表示数字，没有加一个挡住棋盘的讲解员。
5. [DragonBox Numbers](https://www.dragonbox.com/products/numbers)：只读了产品页。应用收费，没有玩。4–8 岁，数字是可以摆弄的角色，多数活动没有计时。用来确认幼儿关不该靠倒计时和生命条；没有借用它的角色。

### 未解决

- 经典模式 `applyHint` 仍从答案里抽一格填上，没有讲理由。
- 经典模式仍有 3 次错误就结束、计时，以及通关烟花。手机上 9×9 和工具很挤。
- 没有单独的准备关。盘面中途离开只保留星星，不保留还没下完的格子。
- 没有 6×6。9×9 难度仍按已知数个数。
- 「听一听」依赖浏览器中文语音，本环境没有人耳确认。
- 趣味和是否易懂只做了设计评估，没有儿童测试。

### 下一步

1. 做三个很短的准备活动：找出一行缺谁、指出两个一样的积木、把 1–4 补齐。仍用现在的积木。
2. 经典提示先查当前盘的冲突，再解释唯一候选，停止直接填答案。
3. 若第 4–6 关的「只剩一个空位」已经稳定，再单做一关 6×6 试水，不和 9×9 绑在同一次改动里。
